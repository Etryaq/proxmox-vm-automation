# Proxmox VM Automation 🚀
A simple and effective Bash script to automate the provisioning of Virtual Machines in Proxmox VE. 

## Use Case
Reduces manual configuration time when scaling infrastructure or re-provisioning standardized environments after hypervisor migrations (e.g., transitioning workloads from VMware ESXi to Proxmox).

## How to run
1. Make the script executable: `chmod +x create_vm.sh`
2. Run the script: `./create_vm.sh <New_VM_ID> <VM_Name>`
